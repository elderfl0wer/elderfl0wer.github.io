# elderfl0wer.org

Static site, no build step.

```
index.html, software.html, writings.html, miscellany.html, extra.html
writing/            published posts
_templates/         post templates (copy into writing/, not published as pages)
assets/css|js|img   styles, script, images
```

New post: copy `_templates/post-1.html` to `writing/<name>.html`, edit, add a link in `writings.html`.
